## نظرة عامة (Overview)
هذا المشروع عبارة عن **نظام خبير (Expert System) ذكي ومتقدم** يعتمد على محرك قواعد (Rule-Based Engine) باستخدام تقنية التسلسل الأمامي (Forward-Chaining).

تم تصميم النظام لأتمتة عملية التحليل العميق للشيفرة المصدرية (Source Code) المكتوبة بلغة **JavaScript**. يقوم النظام بتقييم الكود بدقة متناهية بناءً على مبادئ الكود النظيف (Clean Code) وهندسة البرمجيات المعتمدة (استناداً إلى معايير *Robert C. Martin* و *Martin Fowler*) لاكتشاف العيوب التصميمية (Design Flaws)، الروائح البرمجية (Code Smells)، والمشاكل الهيكلية المعقدة.

---

## القدرات الأساسية (Key Capabilities)

* **التحليل الهيكلي العميق (AST Parsing):**
  يقوم النظام بتحويل كود الـ JavaScript الخام إلى شجرة بنية مجردة (Abstract Syntax Tree) متطورة باستخدام مكتبة `pyjsparser`، مما يسمح بفهم سياق الكود بدقة.

* **التحليل الشامل للمشروع (Project-Wide Analysis):**
  يتميز النظام بقدرته على تقييم ملفات متعددة ومترابطة برمجياً في نفس الوقت. هذا يسمح باكتشاف المشاكل عبر الملفات (Cross-File Issues) مثل الدوال غير المستخدمة (Dead Code) أو تكرار مجاميع البيانات (Data Clumps).

* **محرك الاستدلال الذكي (Inference Engine):**
  يستند إلى مكتبة `experta` لتنفيذ القواعد المنطقية بطريقة فعالة (Alpha Network Pattern Matching). يتم استخراج "الحقائق (Facts)" من الكود، ليقوم المحرك بمطابقتها وإصدار توصيات ذكية فورية لحل المشاكل.

* **بيئات التشغيل المرنة (Execution Modes):**
  صُمم ليدعم التكامل التام مع سير العمل (Workflow) الخاص بالمطورين. حيث يوفر:
  - **واجهة مستخدم رسومية (Web UI):** سهلة الاستخدام ومناسبة لعرض التوصيات بطريقة بصرية.
  - **واجهة سطر الأوامر (CLI):** مثالية للتكامل الآلي مع بيئات الـ CI/CD والسكربتات.

##  القواعد المدعومة حالياً (Supported Rules)

تتضمن قاعدة المعرفة (Knowledge Base) الخاصة بالنظام مجموعة من القواعد الاحترافية المبرمجة بدقة، مصممة لاكتشاف أعقد الأخطاء التصميمية:

1. **التعقيد الهيكلي (Cyclomatic Complexity):** يكتشف الدوال التي تحتوي على تفرعات منطقية زائدة تؤدي إلى صعوبة الصيانة (الحد الأقصى المسموح > 10).
2. **التشعب العميق (Deep Control Flow Nesting):** يعالج الـ *Arrow Anti-Pattern*، حيث تكون الجمل الشرطية أو الحلقات متداخلة بشكل يعيق القراءة (الحد الأقصى > 3 مستويات).
3. **التخلص من الكود الميت (Dead Code Elimination):** يفحص المشروع بالكامل لتحديد الدوال المعرّفة والتي لم تُستدعَ مطلقاً ضمن نطاق التحليل.
4. **البيانات المتكررة (Data Clumps):** يحلل الدوال عبر الملفات المختلفة ليكتشف تمرير نفس قائمة المعاملات الطويلة، وينصح بتحويلها إلى كائنات (Parameter Objects).
5. **تعدد المسؤوليات (Multiple Responsibilities):** *(قاعدة جديدة)* يقوم بتحليل الأهداف من استدعاءات الدوال الداخلية لاكتشاف انتهاك مبدأ المسؤولية الواحدة (SRP) (الحد الأقصى المسموح > 2 مهام مختلفة).
6. **عدد المعاملات الزائد (Too Many Parameters):** يحدد الدوال التي تعتمد على قائمة معاملات ضخمة تؤدي لتعقيد الاستخدام (الحد الأقصى المسموح > 4 معاملات).
7. **حجم الدالة (Method Length):** ينبه عند تجاوز الدوال للحجم المثالي لتصبح معقدة المهام وصعبة القراءة (الحد الأقصى > 20 سطر كود).
8. **الأرقام السحرية (Magic Numbers):** يكتشف القيم الرقمية الصلبة (Hardcoded) غير الموثقة ويوصي بتحويلها لثوابت صريحة.
9. **تسمية المتغيرات (Variable Naming):** يحلل أسماء المتغيرات للتحقق من كونها معبرة، ويتجنب الأسماء المبهمة والمختصرة جداً لتسهيل فهم الشيفرة.

##  التثبيت وإعداد البيئة (Installation)

بخطوات بسيطة، يمكنك تجهيز النظام للعمل محلياً:

1. قم باستنساخ المستودع (Clone the repository).
2. أنشئ بيئة بايثون وهمية (Virtual Environment) وقم بتفعيلها.
3. ثبّت الاعتماديات الأساسية من خلال تشغيل الأمر التالي:

```bash
pip install -r requirements.txt
```

##  تعليمات الاستخدام (Usage Instructions)

يوفر النظام طريقتين احترافيتين للاستخدام حسب احتياجات هندسة البرمجيات لديك:

### 1. واجهة الويب التفاعلية (Web Interface)
مثالية للحصول على تقارير واضحة وتفاعلية لتتبع جودة الكود:

```powershell
# 1. تجاوز سياسة التنفيذ في أنظمة ويندوز (إن لزم الأمر)
Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process

# 2. تفعيل البيئة الوهمية
.\.venv\Scripts\activate

# 3. تشغيل خادم التطبيق
python app.py
```
*ملاحظة: انتقل إلى `http://127.0.0.1:5000` في متصفحك. أدخل المسار المطلق (Absolute Path) لمجلد مشروع JavaScript المراد تحليله.*

### 2. واجهة سطر الأوامر (CLI)
الخيار الأمثل للمطورين وأتمتة العمليات (Automation):

```powershell
.\.venv\Scripts\python.exe main.py "C:\absolute\path\to\javascript\project"
```

##  البنية المعمارية للنظام (System Architecture)

تم تقسيم وتصميم المشروع بطريقة احترافية تضمن قابلية التوسع والصيانة (Modularity and Scalability):

*  **`analyzer/`** : الطبقة الأساسية لقراءة الـ JavaScript وتحويلها إلى AST لاستخراج ومسح الحقائق المنطقية الدقيقة (`FactExtractor`).
* **`core/`** : قلب النظام الخبير وعقله المدبر؛ يحتوي على تعريفات الحقائق (`Facts`)، وإعدادات القواعد (`Rules`) المكتوبة بكفاءة، بالإضافة لمحرك الاستدلال (`experta` KnowledgeEngine).
*  **`models/`** : يحتوي على هياكل البيانات المعيارية (Data Structures) المستخدمة لبناء توصيات إعادة الهيكلة (`Refactoring Recommendations`).
*  **`utils/`** : طبقة الخدمات والأدوات التي تتعامل مع تنسيق المخرجات وإنشاء التقارير النهائية الشاملة للمستخدم.
*  **`app.py` / `main.py`** : نقاط الإدخال الرئيسية (Entry Points) لتشغيل النظام بنمط واجهة الويب أو سطر الأوامر.
